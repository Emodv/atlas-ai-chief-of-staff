# Talk to Atlas

Atlas is designed to be used from ChatGPT as the primary conversational interface.

Use these prompts:

- `Atlas, give me my morning briefing.`
- `Atlas, what should I do now?`
- `Atlas, who needs my attention today?`
- `Atlas, where can I make or protect money today?`

Daily use should not require GitHub, Claude Code, Vercel, or Supabase.

If ChatGPT cannot authenticate to Atlas, check the production OAuth health endpoint and the Atlas.Moda Supabase project status before changing application code.
