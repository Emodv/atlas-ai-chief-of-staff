Atlas Google onboarding requests read-only access to the user's Google workspace data so a single Google consent flow can both authenticate the user and connect their first data sources.

Requested scopes:
- openid
- email
- profile
- Gmail read-only
- Calendar read-only
- Contacts read-only
- Drive read-only
- Docs read-only
- Sheets read-only

New users remain in Safe Mode with execution OFF. These scopes are for observation and first-scan value only.
